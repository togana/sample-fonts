Adobe Fonts only font-weight fallback check

Adobe Fonts のみで Latin avenir-next-lt-pro を 500 / 700、 Japanese source-han-sans-japanese を 400 / 700 で読み込み、 ブラウザの font-weight 代替ルール による近接フォールバックを確認するページです。 font-synthesis: none を指定して、合成による疑似ウェイトを抑止しています。

  • font-weight: 400 → Latin は 500 / Japanese は 400 にマッチする想定
  • font-weight: 700 → Latin / Japanese ともに 700 にマッチする想定
